## Running locally

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
node index.js
```

Open `http://localhost:8080`.

## Structure

- `index.js`: Express server and Pug rendering.
- `config/site.json`: centralized identity and social links.
- `public/includes/links.pug`: reusable link component.
- `public/content`: Portuguese and English page copy.
