## Executando localmente

### Pré-requisitos

- Node.js 18 ou superior
- npm

### Instalação

```bash
npm install
node index.js
```

Acesse `http://localhost:8080`.

## Estrutura

- `index.js`: servidor Express e renderização das páginas Pug.
- `config/site.json`: identidade e links sociais centralizados.
- `public/includes/links.pug`: componente reutilizável dos links.
- `public/content`: textos da página em português e inglês.
